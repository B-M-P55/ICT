# H2O2U

**H2O2U** is a web-based drinking water delivery system designed to make ordering water easier and more convenient in Myanmar.

## About

Customers can browse water products, place orders, manage delivery addresses, and choose payment methods. Admins can manage products, inventory, orders, payments, and delivery areas.

## Features

* Customer Registration & Login
* Product Management
* Shopping Cart & Checkout
* Order Management
* Inventory & Stock Management
* Address Management
* Delivery Area Management
* Payment Management
* Admin Dashboard
* Cash on Delivery (COD) & KPay

## Technologies

* HTML
* CSS
* JavaScript
* PHP
* MySQL / MariaDB
* Bootstrap

## Initial Delivery Areas

* Insein
* Mayangone
* Hlaing

## Project

H2O2U is a group student project created to solve real-world drinking water delivery problems and apply web development, database, and teamwork skills.
